# 精确计费方案（仅技术设计）

当前统计为 Clash 连接快照的已观测下界。两次快照间结束的连接和末次字节不可从快照恢复，不能靠缩短轮询、全局快照或整机网卡计数补出精确 Tag 账单。

可评估 sing-box 上游提供按真实入站的单调持久字节计数，或可靠的连接建立/关闭事件；事件必须包含稳定真实入站 Tag、双向最终计数、进程 epoch 和单调序列。Agent 使用有界本地持久队列、可幂等报告及中心事务去重，对计数重置、丢事件、崩溃、断网回放和多级 selector 单独测试。接口能力需要按实际 sing-box 版本核实。

eBPF 仅能作为另一个受控适配器方案：需要内核和权限支持，并建立 sing-box 连接到实际 Tag 的可信映射。多个 Tag 复用同一代理端点时，仅凭 socket 或目的 IP 无法准确区分；TLS/隧道开销与业务有效字节也须明确计费口径。

这些方案可能需要生产 sing-box 的配置、版本或代码修改，须独立评审、授权和灰度验证。本统计方案不会安装 eBPF 或把观察数值改标为精确账单。另行授权的受限出站配置与重启流程见 CONTROL.md。
