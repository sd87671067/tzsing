# 入站节点与控制验证记录

在远程服务器新建干净 worktree，基线为公开仓库 main `7e84114e2e5ae82e123d03d2c2bd78a53677f21c`。UI 仅只读参考成熟组件的 SVG、材质和生命周期；未复制私有业务源码。没有修改第三方服务。

现网 sing-box 1.13.15，由 systemd 直接启动。实际 Clash `metadata.type` 包含 `协议/入站TAG`，`chains` 则是出站链路。当前权威配置只有两个客户端入站，其中一个 VLESS 入站按多用户规则分流；没有把多个出站、认证用户或内部 SOCKS 伪装成新入站。

实际验证：

- 定向 Go 测试：adapter/model/store/server/control/cmd；未运行全仓库测试或 race。
- 新测试覆盖共享 direct、多级 selector/URLTest、条件/未知路由、逐入站差分、去重、历史/名称/权限迁移幂等、旧缓存隔离。
- 权限、CSRF、一次性票据、撤权、复制与查看权限隔离；监控、管理、历史与审计无测试凭据泄露。
- 标准 VLESS+REALITY 公钥/参数、SIP002/SS2022 用户信息编码。Shadowrocket/v2rayN 使用剪贴板导入；没有原生客户端安装，未声称原生客户端导入实测通过。
- 独立合成 sing-box 实例：两个 Shadowsocks 入站共享 direct，实际更换一个到合成 SOCKS 出站，两入口均可连接；另用本次创建的独立 systemd 临时单元验证相同 restart 生效路径；实际恢复原映射；无效配置不写入；切换后注入健康失败，自动恢复原文件与进程并验证两入口。
- Chromium 和 WebKit，320/375/390/430/768/1024/1440px：深浅主题、24px SVG、无横向溢出、Modal 焦点/滚动锁/关闭、脏表单确认、事件隔离、按需链接、复制/导入、确认更换/恢复、实时卡片/Canvas/Modal 身份保留、普通用户拒绝。
- 浏览器剪贴板使用隔离桩，配置按钮由合成受限控制器响应；实际 sing-box 切换另由上述独立 Go 集成测试验证，没有拿生产数据库或配置当测试夹具。
- Python 原清单及新增入站路由测试、JS 语法、Go build、diff 检查；发布前扫描生产 UUID/私钥/密码/Token 及常见编码，不提交运行资料或凭据。

应用限制：没有无中断热更新承诺；确认应用会重启 sing-box，所有当前连接短暂重连。外部工具不共享本控制器的锁；哈希冲突拒绝覆盖，不能保证不配合写入者的全局事务。未知路由不显示虚构唯一出口；流量仍是连接快照已观测下界，不能精确计费。出口路径变化后，未重新证明的旧出口不会当成新路径结果。

现网发现另一个工具可改写同一生产配置，且不使用共享 flock。按安全要求，生产部署启用分享和脱敏预览，配置应用/恢复的后端写入门禁保持关闭；这不是前端隐藏。未修改该工具或生产 sing-box。

最终安全补充：生产写入关闭时，控制器发现中断事务也保留记录并拒绝自动恢复；校验临时配置移至私有状态目录。补充定向测试、Go build 通过。Chromium/WebKit 补测只读门禁：更换/恢复菜单禁用，复用原编辑器提供独立只读解析预览，确认按钮禁用，应用请求数为零。生产控制器附加只读配置目录及隔离服务管理 socket 的 systemd 限制。
