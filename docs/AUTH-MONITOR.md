# 入站、认证身份与数量诊断

独立 inbound Tag、同入站的认证用户、实际出站、Selector/URLTest 必须分开计数。客户端监控只展示前两者；同协议、同 IP、共享出站、零连接及未知路由均不影响身份存在。

VLESS 已迁移到 UUID 摘要身份，一 UUID 一张监控卡片；改名保持身份，UUID 轮换成为新节点。共享父入站保留统计和诊断，不重复展示。旧用户名摘要键仅在首次迁移时保留 ID、授权与历史，详见 [UUID 管理](UUID-MANAGEMENT.md)。非 VLESS 保留原名称摘要兼容模式。

标准 sing-box Clash `/connections` 的 `metadata.type` 可表示 `协议/入站Tag`，通常没有认证用户字段。导出器不会启用身份流量归属。认证身份卡片保留，速率、累计及账期使用量为不可用；连接流量只计入相应入站未归属诊断桶。入站自身也未知时，只增加全局无法归属连接计数。不会通过源 IP、目标、协议、出口 IP、路由选择或用户顺序推断认证身份。

可选扩展只有在运维独立核实数据源可靠提供 `metadata.inboundUser`（原始认证名称）后，才可在相应清单入站显式设置 `user_field: inboundUser`。标准导出器始终不设置。Adapter 对该字段做同样的摘要，并且仅匹配该入站当前已配置认证 ID。未匹配连接仍留在入站未归属流量。一个连接只选择一个身份桶；连接 ID 去重、单调差分和首快照基线继续生效。轮询统计依然只是已观测下界。

管理员必须同时授予服务器及精确身份键；父入站授权不向下展开，新增身份不会继承授权。普通用户响应不包含全局清单数量、认证摘要或其他身份。退出与撤权沿用现有会话/WebSocket 校验。身份卡片无法证明独立路径时，IP Modal 明确说明，不调用父入站的其他用户凭据。原有入站控制接口只接受原入站键。

清单每次配置变化重新导出，Agent 沿用原 30 秒刷新周期。清单暂时不可读时保留已知身份，只将路径标为未知；Agent/Clash 暂时断连时卡片保留。单份清单最多 512 个展示身份，与上报协议限制一致。

管理员服务器卡片的“身份数量诊断”包含：实际入站、认证身份、Agent 发现、上报、后端可见/过滤、授权可见/过滤、前端展示/搜索筛选隐藏及原因。`GET api/admin/monitor-diagnostics?user_id=<id>` 可核对指定用户在各服务器的授权计数；端点只供管理员，返回聚合计数，不返回密码、认证名称、UUID 或密钥。身份计数中单密码入口只算入站，不额外虚构具名用户。

服务器状态复用既有 Host 采集和 WebSocket：CPU/内存 Canvas 环图、磁盘紧凑进度条、网络双曲线、负载小趋势、sing-box 标记及次要运行时间。网络/负载每服务器最多保留 120 个本次会话采样，按报告时间去重；长断连后重新开始，不补造过去。旧采样离线时显示过期状态，主机未授权不绘图。Canvas 继续复用现有统一绘制调度、离屏暂停和减少动画设置；不增加服务端采样频率或动画。

## 定向验证

先在操作者指定的正式测试私库最新 main 的干净目录核对远程与 SHA，再放置隔离的 tzsing 测试工程；不能改用其他业务仓库或生产数据库。运行 tzsing 的 Go 定向包测试、Python 清单测试、`test_monitor_modal.cjs` 和 `test_auth_monitor.cjs`。

浏览器夹具 `stage_auth_monitor.py` 必须显式提供 `TZ_SYNTHETIC_STAGE=1`、`TZ_TEST_STATE`、`TZ_TEST_BINARY`、`TZ_TEST_CERT`、`TZ_TEST_KEY`。默认只绑定回环 33080/33443；`TZ_AUTH_FIXTURE=1` 添加两个认证身份。证书、数据库和随机测试密码只保存在隔离状态目录，不能提交。浏览器脚本还需 `PLAYWRIGHT_MODULE`、`TZ_TEST_BASE=https://127.0.0.1:33443/inboundtest`、`TZ_TEST_PASSWORD_FILE`，通过 `TZ_BROWSER=webkit` 切换 WebKit。夹具数据全部为显式合成数据，不能作为生产流量或性能证据。

验证覆盖每层数量、共享出口/同 IP、无连接、未知路由、多认证用户、重复连接不重复计量、可靠扩展与未知用户、部分授权/撤权、断连恢复、热更新和 ID 稳定。浏览器分别在 320/375/390/430/768/1440px、Light/Dark、减少动画下验证；检查采样缓冲、服务器/节点/Canvas DOM 复用、Modal 和菜单隔离。部署前保留健康镜像、Agent 二进制、导出器、配置与 SQLite 在线备份；只更新 tzsing 自有服务。禁止清理数据库或业务缓存。
