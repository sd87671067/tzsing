# UUID 出站授权与个人出站

管理员用户管理中的“逐 UUID 出站与个人出站权限”，分别设置更换/恢复、创建、编辑、删除，以及这个 UUID 可绑定的出站集合。原有节点可见权限和服务器授权仍必须同时成立。旧全局 change 权限不再足以让普通用户任意更换出站；升级不会自动扩大旧授权。

普通用户从节点操作菜单进入“个人与授权出站”。个人节点由 Control 生成唯一 Tag，SQLite 用独立随机 ID 保存身份和创建者；客户端不得指定 Tag。新节点只给创建时指定且已授权的 UUID 建立出站许可，其他 UUID 需要管理员明确授权。用户删除后，只要其个人出站仍保留，新增用户就不会复用该创建者 ID，防止继承旧出站。全局节点和个人节点共用出站引用，切换只修改目标 UUID 的精确路由；不会更改共享代理或其他 UUID。

个人节点列表仅显示名称、独立 ID、创建者 ID；不返回服务器认证资料、密码、原始链接、内部执行计划或生产配置。认证资料仅存在 Control 的内存计划、root 控制的 sing-box 配置及 0600 恢复快照中，属于受控存储，并未宣称数据库加密。Web 不挂载生产配置。创建/编辑会验证并固定公网目标 IP，保留 TLS 服务名，防止随后通过 DNS 重绑定访问管理地址。编辑需重新提交完整链接；正在被路由引用的个人节点需先恢复绑定，再编辑或删除。管理员可以查看和管理全部个人节点，并逐 UUID 授权共享。

预览和应用都校验当前用户、UUID、独立出站 ID 三者关系。一次性 nonce 绑定会话、用户、UUID、出站和操作；不能通过变更请求参数或猜 Tag 绕过。授权检查与生产变更串行，WebSocket 每次快照继续使用当前服务器/节点权限。仅有复制节点权限不会触发出站目录读取，也不会获得更换权限。

撤权策略是先恢复该用户受影响 UUID 的原始出站，再提交撤权；恢复失败返回 409，明确表示撤权未完成，保留原权限，禁止虚报已撤销。删除或停用用户、改变节点可见权限和操作权限也会先处理其已有绑定。权限面板和这些会触发恢复的 Web 操作保留二次确认。绑定意图先于生产应用持久化，异常中断后可以保守恢复；不以空白数据库记录假装生产路由已恢复。

# 复杂链式检测

Control 按实际配置递归收集 detour 依赖。HTTP（含 TLS）、SOCKS、VLESS、Trojan、Shadowsocks 等客户端节点保持协议参数。Selector/URLTest 从生产本机 Clash GET 接口读取当前成员，在隔离客户端内固定该成员后检测；不更改生产选择。后台探针也同步这些选择，选择变化会失效并重新生成路径证明。

出口 IP 只来自通过该完整链路获取的响应，不使用代理服务器地址作为出口。循环、缺失引用、未知动态成员、缺少运行时接口、不支持的本地文件依赖或检测期间成员变化均明确失败，不回退到默认网络伪造结果。支持现有配置的选择和检测；本次没有增加从 Web 创建任意 Selector/URLTest 拓扑或读取本地证书文件的能力。

正式测试宿主为 sd87671067/go-emby-test main 545b840c953095c506dc63402cec35910e8d3e66。隔离命名空间使用三层 HTTP/SOCKS 传输验证 HTTP、HTTPS、SOCKS、VLESS、Trojan、Shadowsocks 和固定已证明成员的 Selector/URLTest；授权测试覆盖跨用户、跨 UUID、猜 Tag、nonce 重放、预览后撤权、个人节点生命周期、恢复失败和旧复制权限兼容。Chromium/WebKit 检查授权面板、个人出站表单和确认流程，以及 320/390/1280 宽度、明暗主题。界面模拟测试不代表外部代理可用性。
