# 出站更换与个人出站

普通用户的唯一更换开关为用户管理 → 操作权限 → 允许更换出站 IP（user_operations.change）。关闭时入口隐藏，preview/apply 均拒绝；一次性确认不能冻结权限。管理员继续使用原有独立控制权限与配置安全事务。

可选集合实时取用户获授权监控的全部 UUID 在控制器当前配置中实际路由引用的出站去重并集，加该用户自己创建的个人出站。列表不依据浏览器、别名或旧报告授予权限。条件路由保留可能引用及回退；selector、urltest、detour 按原有引用使用，不展开成额外授权。其他用户个人出站始终排除。API 接收不透明 ID，预览和应用均重新校验身份、监控授权、开关、所有权与当前路由。

监控授权撤销、操作权限关闭、用户停用或删除只改变访问能力，不请求配置恢复，不删除共享出站，不修改现有 UUID 路由。UUID 身份映射、uuid_bindings、历史流量、月额度、有效期策略和审计保持原实现。升级不创建旧 uuid_permissions/uuid_outbound_grants；已有两表仅作惰性历史记录保留，不读取、不写入、不迁移成新授权、不 DROP，便于回滚。

更换入口直接展示列表并标记当前引用，保存期间使用现有按钮 Loading 与防重复提交；预览及确认沿用配置校验、原子应用、健康检查与失败回滚。个人出站管理单独保留添加、编辑、检测、删除，不再提供第二条绑定或恢复链路。个人出站不返回密码、原链接或控制器计划；编辑须重新提交完整链接。实际引用中的出站禁止编辑/删除，保留生产配置 CAS 和共享 443 安全边界。
