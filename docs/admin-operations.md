# UUID 操作与部署边界

用户操作权限保存在 SQLite `user_operations`，与服务器/节点授权分离。
新增表没有默认授权，不从旧的管理员 `control_permissions` 向普通用户复制。
管理员在用户行展开后单独保存节点访问和操作权限。普通用户的重命名是个人显示别名；全局名称仍只由管理员维护。
撤销操作权限清除待确认 nonce 并断开用户 WebSocket；凭据导出完成前再次校验操作与节点授权。
凭据一旦合法复制到客户端，撤销面板操作权限不能收回已经复制的凭据。

出口图标只检测当前节点选择的实际出站。控制器要求配置哈希、路由版本和专用回环 SOCKS 映射证明一致；不允许中转回退服务器默认网络。
固定 HTTPS 目标按 IPv4/IPv6 各请求一次，每请求 6 秒，控制器串行执行，每身份/出站 30 秒一次，Web API 另有限流。
成功的路径 IP/国家/时间保存到 SQLite；失败保留上次结果。HTTP 成功不证明 ICMP、入站公网可达或所有网站可达。

逐 UUID 更换使用 `inbound` 与唯一 `auth_user` 双重条件；保留原有拒绝和其他用户资料。
恢复使用原始快照和精确新增规则，拒绝覆盖外部变更。共享多用户监听器不接受无身份的整入站变更。
停用插入精确拒绝规则，启用只撤销已记录且版本一致的本系统停用规则。
删除仅移除目标身份，保留监听器和其他 UUID；最后一个 UUID，以及仍有出站快照的 UUID，拒绝直接删除。

应用先验证原配置和当前健康、候选配置，再准备持久备份和事务日志；锁内再次比对版本，原子替换文件。
预览 nonce 绑定用户、会话、节点、动作和短时有效期，一次使用。二次确认列出目标、修改、共享端口/其他 UUID 数及整个实例监听器范围。
sing-box 使用实例重启，不能承诺只重启共享 443 的单个 UUID。旧连接可能中断，不提供无证据的恢复时间估计。
服务/路径检查失败时恢复原始字节、原快照并重启验证；并发版本变化或备份/原配置不可验证时拒绝覆盖或执行。
中断事务只在明确启用写入的控制服务恢复流程内处理。部署不启用生产写入或重启生产 sing-box。

## 本机尚未具备的执行条件

本机 sbbot 仍独立执行配置原子替换，不使用控制器的 flock。
控制器的私有锁与 CAS 只能发现部分冲突，不能阻止不合作写入者在最后检查后改写。
因此本次保留 `write_enabled=false`，不能把二次确认作为并发协调证明。
生产开放前必须让全部写入者通过同一事务入口/锁协议，或有可核实的唯一配置写入者。
本次没有修改、暂停或重新配置 sbbot，生产写入冲突**没有解决**。控制器额外拒绝检测到活跃 sbbot 或无法核实进程的应用/事务恢复；这只是已知写入者保护，不能代替完整协调。

到期自动停用、可靠月账单/超额封禁尚未实现；两项不保存假限制，也不声称生效。
逐 UUID 启停、删除、更换及恢复的执行器已在独立 sing-box 子进程验证，本机生产应用仍受上面的写入者门槛保护。
