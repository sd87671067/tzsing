# UUID 出口关联修复

UUID/name 继续作为监控及授权身份；流量差分、累计与原生计数逻辑不变。

原断点：生成认证身份时清空 Egress，Agent 无法按实际 Tag 取得原有专用出口探针缓存；详情接口也提前拒绝身份检测。

现在在完整认证规则或已核实 inboundUser 完成身份归属之后，独立读取连接 chains[0]（sing-box 将实际出站置于反转后链首）。多个连接的实际出口保留为 egresses 数组，只有单出口才兼容填充 Egress/IP。空闲保留相同配置及运行时选择下的最近路径；精确认证规则可解析 Selector/URLTest 的当前成员。没有证据的路径显示“路径待检测”。

IP 继续经已有、受审查的实际出站专用 SOCKS 探针取得。不使用默认网络替代缺失的中转探针。配置摘要、路径证明状态与运行时选择共同构成缓存作用域；变更即失效，旧作用域进行中的检测也不能写回新缓存。不同 UUID 仅共享出口证明，不共享流量。

SQLite 报告 JSON、API 和 WebSocket 保留完整路径列表。权限过滤仍先于展示；隐藏内部 Tag 时同时隐藏路径内的 Tag 和证明字符串。详情按服务器保存的路径索引选择目标，受限 Agent 独立核实 UUID、实际出口与路径版本；网络操作后再次核实身份、权限及路径。客户端不能传入任意出口或探测地址。

卡片仅显示路径类型、国家及 IP，多个出口分别列出。检测状态仅保留在详情。沿用已有 Modal、Toast、SVG、焦点管理、动画及设计变量；来源切换使用已有玻璃材质和前景色，不新增覆盖 CSS。

定向验证在私库 sd87671067/go-emby-test 的独立、干净 main 测试目录中放置 tzsing 候选源码，使用隔离 SQLite、模拟控制 socket 与自签 TLS。覆盖 Direct、中转、URLTest/Selector 切换、多出口、共用出口流量隔离、空闲、失效缓存、授权及撤权；WebKit/Chromium 覆盖六档宽度与深浅色、来源切换、手动检测、Toast、WS 和键盘焦点。移动 WebKit 模拟不代表 iPhone 真机验收。

显式只读检查使用已有 Clash GET 和已有受审查 SOCKS 探针，不改写或重启生产 sing-box。真实 Direct/中转均取得 IPv4；IPv6 不可用时不伪造，也不影响 IPv4 成功。
