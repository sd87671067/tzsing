# UUID 执行状态

## 实际执行与生产激活

`policy/` 的 v2 gate 集成到 sing-box v1.13.15 的 VLESS 认证后 TCP/UDP 入口，独立于 Clash tracker。UUID 摘要是稳定身份，原 metadata.User、auth_user 路由、共享监听器和 REALITY 配置保持原值。`Qualified` 仅声明此版本通过隔离验证；Control 还必须配置 `policy_db`，并读到相同版本、存活进程及完全匹配的 UUID/认证名注册证明，才能开放额度和到期保存。普通心跳、旧候选、前端解禁或 SQLite 数字都不能开启执行能力。

**仅升级 Web/Agent/Control 不会激活生产限制。** 安装候选 sing-box、设置独立的 `TZSING_POLICY_DB` 和 systemd 写入路径后，需要操作者批准重启整个生产实例。首次激活会中断现有连接；以后额度/日期修改不需要重启，新增 UUID、启停、删除和路由配置变更仍须应用预览及确认。

## 计量与崩溃语义

SQLite 使用 WAL、FULL synchronous 和 BEGIN IMMEDIATE；按入站与 UUID 分开保存策略、账期用量、上下行实际结算和未决预留，不使用 Clash 快照扣额度。TCP 空闲读取不提前预留额度，UDP 保留协议所需缓冲头尾空间，优化复制不能绕过 gate。

到期拒绝准入；额度检查同时考虑已结算和未结算预留。0/空额度表示不限额。修改后即时重新评估；按配置的时区和每月重置日计算账期，重启继续使用同一数据库。月界前的崩溃未决项不会污染新账期。

网络写入和数据库提交之间不能形成同一个原子事务。崩溃中断的写入保留未知预留，**不会伪造为实际已用，也不会直接退款**。重启后该预留保守占用当前账期余额，余额足够仍可准入，其余 UUID 不受影响。UI 分别展示已结算和未结算预留。这是可保守执行的载荷额度，不声称完整崩溃场景下的精确运营商计费。TLS 统计包含穿过 VLESS 认证边界的目标 TLS 记录字节。

执行器持有独占进程锁。数据库故障拒绝载荷；不能因为保存元数据成功显示限制已执行。Control 的只读数据库连接使用运行中执行器 owner 判断未决状态，避免把正常并发 I/O 错认成崩溃。

## 隔离验证

正式宿主为私库 `sd87671067/go-emby-test` main `545b840c953095c506dc63402cec35910e8d3e66` 的新工作区，tzsing 候选位于隐藏工程，业务源码未修改。测试包括：

- 独立网络命名空间中的共享 REALITY TCP 443，14 UUID 并发、112 短连接及精确载荷比较。
- 大于 1 MiB 的 Vision TLS 响应，与目标端 TLS 字节逐方向核对。
- 实际 UDP 回显、逐包用量和到期阻断，未开启 Clash API。
- Control 预览/应用 → SQLite → 实际到期拒绝/延期恢复、超额拒绝/调高恢复。
- SIGKILL、重启恢复、账期切换、未知预留保守占额、独立 UUID 隔离。
- UUID 新增、共享监听、独立路由、恢复，以及切换/健康失败后的配置回滚。
- 管理员鉴权、CSRF、一次性会话 nonce，API/WS 显示开关过滤。

外网定向测试只从本机 root 安全配置读取凭据，不提交凭据、真实代理地址或现场配置。泰国代理使用 sing-box HTTP CONNECT 和 SOCKS 均可取得相同出口；HTTP 请求约 5.9 秒，旧 4 秒 TLS/6 秒总超时会误判。检测扩大预算并提供固定 HTTPS IP 目标回退，协议转换不保留 SOCKS 专属字段。

## 界面与信息来源

导航分入站/出站新增入口；节点管理分段显示。选择已有出站使用共同 Tag 的真实引用，各 UUID 计量独立；删除有引用的出站拒绝执行。名称修改不改变 UUID。UUID 历史与审计不随删除清理。

监控字段只有全局开关开启且存在日期时才显示，不渲染无限期占位；管理编辑通过独立的管理员策略接口读取原值。IPPure 只映射官方实际返回的明确布尔字段 `isResidential`、`isDatacenter`、`isNative`；当前官方示例未给出明确的机房或原生布尔字段，显示未知。`isBroadcast` 不推断为原生或机房，IPinfo ASN 不用于推断。

生产激活必须保留旧二进制、配置、systemd 环境和 SQLite 一致性备份；回滚使用原版本和原配置并验证健康，保留新账本作为审计，不用旧数据库覆盖升级后的流量和授权。
